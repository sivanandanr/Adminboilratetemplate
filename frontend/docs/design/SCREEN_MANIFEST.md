# SmartIAM screen manifest — Phase 1A

Analysis only. This Markdown inventory covers every file in `screenshots/`: **253 PNGs, UI-001 through UI-253**, with one row per original image. Every image was visually reviewed in labelled contact sheets; UI-007, UI-037, UI-181, UI-244 and UI-246 were additionally opened at original resolution for targeted review. Original PNGs, not thumbnails, supplied color samples.

Screen names are human-readable descriptive labels, not validated OCR or functional requirements. The screen type records the dominant visible structure; many references combine lists, dashboards and detail panels. A visible side panel is not proof that it is an interactive drawer. “Navy sidebar / light content” does not imply identical header, logo, spacing or navigation taxonomy.

The source links below point to the actual image filenames. Dimensions and SHA-256 agreement with the existing JSON inventory were checked against all originals. The JSON inventory is retained as historical tooling; this document corrects its UI-010 title, UI-018 composite classification, and several pale-sidebar classifications (notably UI-007, UI-009, UI-222, UI-228 and UI-244). No source PNG or application file is changed by this analysis.
